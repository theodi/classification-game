# Housing data source

`part_1_data.csv` is the original file from the R2D3 repository [jadeyee/r2d3-part-1-data](https://github.com/jadeyee/r2d3-part-1-data). It is stored here unchanged, including its licence header.

Do not edit values in this file. Scripts may only select, filter, and relabel rows when they build the card packs.
