# Working copies

These files are the project's full housing tables. Express does not serve this directory.

- `houses.csv` is the training table, moved here unchanged from `public/data/`. The `group` column still records Groups 1 to 6. The game loads only Group 1, from `public/data/pack.json`.
- `red_cards.csv` is the original evaluation table, including its UTF-8 byte-order mark. It overlaps the training table and contains duplicate listings. The game does not load it.
- `houses_20.csv` is an unused 20-row sample. No page or script in the game reads it.
- `evaluation_pool.csv` is generated by `scripts/build_evaluation_pool.py`. It is the original evaluation rows with training homes removed and exact duplicate listings collapsed to one row. Values are copied, not edited.

Bathrooms and square footage stay in these tables so the cards can be traced to the source. They are not published.
